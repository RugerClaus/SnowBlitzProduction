English Description
This package contains retro-style pixel art snowflakes, perfect for adding a winter atmosphere to your games and creative projects.
It is completely free for both personal and commercial use.
Contents:
- PNG files (individual snowflake sprites)
- GIF files (animated snowfall)
- JSON and Data URI formats
- C files (technical integration examples)
- License file
Usage:
These assets can be easily integrated into GDevelop, Unity, Godot, or web projects.
Ideal for intro scenes, menu backgrounds, or in-game winter effects.
License:
Free to use (including commercial).
Attribution is required — please credit the artist muyuta or publisher Stone Castle Lab in your project.
